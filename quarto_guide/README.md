# Getting started with Quarto

A guide to writing documents that combine text, R code and its output in one Quarto document.

It covers installing TinyTeX for PDF output, creating and rendering a document in RStudio, the Visual and Source editors, code chunks, Markdown basics, the YAML header, controlling which code and output is shown, and adding images and equations.
