# Getting started with R

A first introduction to R and RStudio for students with limited programming experience, covering what is needed before the physical chemistry activities.

The guide goes through installing R and RStudio, finding your way around RStudio, files and the working directory, objects, vectors and functions, packages, reading in data, the core dplyr verbs and the pipe, `log()` and `exp()`, fitting a straight line with `lm()`, plotting with ggplot2, and common errors.
